# Unidad Educativa San Francisco — sitio web

Sitio estático adaptable, preparado para publicarse gratis con GitHub Pages.

## Archivos
- `index.html`: contenido y secciones.
- `styles.css`: diseño responsive, paleta azul/blanco/dorado y animaciones.
- `script.js`: menú móvil, animaciones al desplazarse, galería ampliable y formulario de consulta.
- `assets/img/`: coloca aquí las fotografías y el logotipo institucional.

## Antes de publicar
1. Reemplaza las imágenes de muestra por fotografías autorizadas de la institución.
2. Copia el logotipo institucional a `assets/img/logo.png` si quieres añadirlo; el distintivo “SF” actual es provisional.
3. Edita `script.js` y asigna el correo oficial a `CORREO_INSTITUCIONAL`.
4. En `index.html`, reemplaza los textos de correo, ubicación y atención por datos oficiales.
5. Revisa y confirma la información institucional, los textos y los permisos de uso de imágenes.
6. El formulario abre la aplicación de correo del visitante; no almacena datos ni envía información a un servidor.

Si falta una foto, el diseño muestra una imagen de muestra remota como respaldo. Para una publicación definitiva, recomendamos usar fotos propias con autorización y comprobar que todas carguen correctamente.

## Publicar con GitHub Pages
1. Inicia sesión o crea una cuenta en GitHub.
2. Crea un repositorio público, por ejemplo `ue-san-francisco`.
3. Sube todos los archivos y carpetas de este proyecto, conservando su estructura.
4. Abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)` y guarda.
7. Espera a que GitHub Pages termine la publicación. La dirección aparecerá en esa misma sección.

La URL normalmente será `https://TU-USUARIO.github.io/ue-san-francisco/`.

## Alcance
Este sitio es una página pública informativa. Un portal privado con notas, expedientes o datos personales requiere autenticación y un backend seguro; no se debe publicar información sensible de estudiantes en este repositorio.
